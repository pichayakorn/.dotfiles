# Omarchy baselines

Unmodified copies of the Omarchy files these dotfiles replace (only `starship.toml`:
every other personal setting lives in its own file next to Omarchy's), as they
were when last reviewed (version in `VERSION`). `dotfiles-check` compares them with
the installed Omarchy files to show what Omarchy changed since then; `dotfiles-check
--accept` refreshes them after you've merged the changes you want.

Do not edit these files. Your own changes belong in the stow packages.
